# Personal noncommercial use

Current distributions, starting with v0.21.1, carry the project-specific **Goodnotes Web MCP Personal Noncommercial License 1.0** in [LICENSE](../LICENSE). The license text governs; this page explains the intended scope.

| Example | Covered by the personal-use permission? |
| --- | --- |
| A student organizes their own lecture notes and exercises | Yes |
| An individual runs the MCP locally or self-hosts it for their own private notes | Yes |
| An individual modifies it for a personal hobby or shares a free fork with the same license and notices | Yes |
| The same person pays for their own Goodnotes account, AI client or hosting | Still permitted for otherwise personal use |
| An employee uses it for work, or a freelancer uses it for client projects | No; separate permission is needed |
| A business sells access, bundles it in a commercial product or operates a service for others | No; separate permission is needed |
| A university, school, charity or public body deploys it institutionally, even for free | No; separate permission is needed |

Being a student or employee does not disqualify a person's separate private use. Institutional use and a student's own private learning are different cases.

This is **source-available software with use restrictions**, not an OSI-approved open-source license. It is a custom project license, not a standard noncommercial license with a blanket educational or charitable-organization exception. See the [OSI explanation of commercial-use rights in open-source licenses](https://opensource.org/faq).

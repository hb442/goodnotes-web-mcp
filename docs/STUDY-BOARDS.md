# Lecture to native learning board

The study workflow is an experimental coordinator over the same isolated native Web UI. The MCP server has no language model: the calling assistant reads the lecture, selects source figures, and supplies the explanations and exercises.

1. `goodnotes_prepare_study_board` takes a library item path, its exact expected title, an output title/folder, and a stable request ID. It duplicates the lecture and exports the **copy**. Keep the returned workflow ID. Page excerpts help navigation; they do not replace reading the source, especially formulas and diagrams.
2. `goodnotes_plan_study_board` accepts a title, subtitle, four to 24 cards and one to 12 original figures. Cards must include a summary, questions and answers. Every card has document-page references. Figure crops use normalized page coordinates. Original pixels are rendered locally from the copied PDF; no generated illustrations are used. Optional `layout` chooses one to three columns, `rows` or `compact` flow, and image maximum height. Cards and figures may have a stable `key`, a named `section` and a `span` across columns. `sections` sets the section order. Captions follow actual figure height; they no longer reserve a fixed image row.
3. Inspect the returned local preview. Text width is measured with a conservative margin; long cards, invalid page references, overlapping slots and small figure crops are rejected before creating the output board. Before execution starts, materials may be revised and planned again.
4. Call `goodnotes_run_study_board` once per step until completed or needs-review. The output contains native editable text boxes and image objects. Each block is read back after reload. Text, character formatting, native box style, actual bounds and appearance are checked; images are checked against the inserted pixel checkpoint. A final board PDF and preview support visual review.
5. `goodnotes_study_board_status` reads saved progress without opening a browser. Routine replies omit repeated block evidence; pass `includeEvidence: true` for full receipts and source-export details. After completion, `previewPath` points to the actual exported board; `planPreviewPath` retains the local design. `goodnotes_review_study_board` independently checks an interrupted block only when matching evidence exists. It never repeats an uncertain write. A partial block without sufficient evidence requires individual inspection; creating another workflow is not a safe automatic retry.

## Timing and limits

`elapsedMs` includes preparation, assistant reading/writing and pauses between calls. `activeMs` sums the recorded stages only; it is not the complete wall time and does not measure tokens. Benchmark complete boards separately from isolated card edits. Development/debugging runs should not be mixed into a stable-version performance claim.

The layout currently requires native 100% zoom and a 1440 × 1000 browser viewport. Its bounded columns and spans are not a general design engine. Cards exceeding 620 reserved pixels must be shortened or split by the caller; oversized boards require a separate workflow. For automatic splitting into linked parts and an overview, use the separate collection workflow in [STUDY-COLLECTIONS.md](STUDY-COLLECTIONS.md). Native dimensions are checked against reserved slots. Text measurement cannot guarantee identical line rendering on every platform. A final visual review is still required for readability, figure crops and correct interpretation of the lecture. Page bounds do not prove factual correctness. Concurrent manual edits are not transactional, iPad sync is not acknowledged, and unsupported or ambiguous native controls cause a stop.

Completed workflows can be selectively updated through [study revisions](STUDY-REVISIONS.md). Existing 0.19 plans retain their original geometry and checkpoints; the new layout only affects newly planned material.

Source exports, plans, original figure crops, previews and operation evidence stay in the private runtime directory. These files contain study materials and must not be included in a public release.
